Overview
This repository contains 7 complete geological & geochemical data visualization scripts refined from our full conversation history. All scripts are 100% English, warning-free, and designed for SCI paper publication.
Functions include: age distribution plotting, rock-type classification charts, sample geographic mapping, major element boxplots, categorical statistics (pie + bar charts), and more. All scripts support automatic data filtering, grouping, and high‑resolution vector output.
Environment: Python 3 + Jupyter NotebookDependencies: pandas, numpy, matplotlib, openpyxl
All Script List & Function Description

| Script Name | Function | Output Content |
| --- | --- | --- |
| Age Distribution Plotting Code | Plot age distribution with boxplots and mineral markers | SVG + JPG figures |
| Major Element Boxplot Code | Multi-panel boxplots for major elements with mineral markers | SVG + JPG figures |
| Sample Latitude-Longitude Map | Plot geographic sample distribution with 0.1° minor ticks | SVG map |
| Categorical Distribution (Pie + Bar) | Plot pie charts and horizontal bar charts | SVG charts + Excel |
| Rock Type Classification Plot (V1) | Classify and visualize rock-type data | SVG figures |
| Lithology Classification Plot (V2) | Statistical plotting for lithological classification | SVG vector charts |
| Geochemical Sample Statistics Plot | Sample count statistics and visual distribution | SVG + Excel tables |
