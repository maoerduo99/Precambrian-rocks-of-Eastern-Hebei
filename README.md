# Precambrian-rocks-of-Eastern-Hebei
Code used for compiling the Precambrian dataset

This repository contains two independent modules:
1. Data_Quality_Check: Lightweight, standalone Python scripts for Excel data validation and preprocessing.
2. Data_Visualization_Toolkit: Plotting codes for geological and geochemical research.

Operating Environment: Python 3.8+ / Jupyter Notebook 

Enter the corresponding folder and view the detailed README.md inside.
